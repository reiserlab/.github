# Reiser Lab

We study vision in flies at HHMI's Janelia Research Campus to learn how brains turn seeing into doing. We share the tools, maps and data we build.

**Lab website: [reiserlab.org](https://reiserlab.org)**

[Publications](https://reiserlab.org/publications/) · [Resources](https://reiserlab.org/resources/) · [People](https://reiserlab.org/people/)

## Where to start

| Resource | What it is |
|---|---|
| [Male CNS Cell Type Explorer](https://reiserlab.org/celltype-explorer-drosophila-male-cns/) | Every cell type in the complete male central nervous system, with morphology, connectivity and spatial coverage |
| [Female Adult Fly Brain Cell Type Explorer](https://reiserlab.org/celltype-explorer-drosophila-female-adult-fly-brain/) | Cell types of the FlyWire female brain, in the same format |
| [Visual pathways galleries](https://reiserlab.org/visualpathways/gallery_vpn/) | Cell-type pages for visual projection neurons and visual central brain neurons |
| [neuDiff](https://reiserlab.org/neuDiff/) | Compare two cell types side by side |
| [Modular LED Displays](https://reiserlab.org/Modular-LED-Display/) | Documentation for the G3, G4 and G6 generations of LED arena displays: hardware, firmware and software |
| [Display web tools](https://reiserlab.org/webDisplayTools/) | Browser-based tools for designing patterns and running arenas |
| [Fly Lab Gear](https://reiserlab.org/Fly-Lab-Gear/) | Open hardware for fly experiments, as 3D-print, laser-cut and PCB files |
| [neuView](https://github.com/reiserlab/neuView) | The static page generator behind the Cell Type Explorers |

The full list, with datasets and paper code, is on the [resources page](https://reiserlab.org/resources/).
